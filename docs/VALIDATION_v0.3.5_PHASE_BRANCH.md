# v0.3.5 实测验证：同极性相位分支切换

## 1. 采样链已经稳定

本轮上传的 v0.3.4 导出：

```text
有效采样率          125.000 Hz
采样抖动 p95        0.003 ms
SQI                 99.94%
```

因此红框中的错位不能继续归因于采样阻塞。

## 2. 根因：同一周期内存在两个同极性局部最大值分支

为了做工程回放，在平滑 PPG 上提取显著主脉搏峰作为离线参考。
该参考只用于 A/B，不是同步 ECG 真值。

v0.3.4 固件 Winner：

```text
参考主峰 ±40 ms 内              32.1%
距参考主峰 >120 ms              67.9%
次级相位分支占比                 67.9%
相位分支切换次数                 47
```

RR 异常与分支切换高度相关：

```text
发生分支切换时异常比例            53.2%
没有分支切换时异常比例            2.1%
```

两个分支的 Winner 分数也明显分离：

```text
主峰分支平均 Winner 分            0.850
次级分支平均 Winner 分            0.627
```

v0.3.4 模板层大量出现 `timing_quality≈0.209`：

```text
占比                             58.7%
```

这个值对应模板相关度落到低区间，只剩不确定度锐度项贡献。
说明 ±120 ms 搜索窗口经常根本触达不到正确主峰。

## 3. 形成机制

```text
同一物理心搏
   ├─ 较早的次级同极性局部峰
   └─ 稍晚、形态更强的主峰
             ↓
v0.3.4 在 phase≈1.06 即开始决策
             ↓
较晚主峰尚未进入 Candidate Pool
             ↓
0.36 timing 权重进一步偏向“更靠近预测时刻”的早分支
             ↓
Winner 在两个同极性分支之间切换
             ↓
RR 突然缩短/延长约 0.2–0.35 s
             ↓
桌面 ±120 ms 模板搜索无法跨分支
             ↓
低质量回退 + HRV INVALID
```

## 4. v0.3.5 固件修复

### Winner 决策延后

```text
正常决策 phase
1.06 → 1.40
```

让同周期较晚主峰有机会进入候选池。

### 形态成为主要裁判

Candidate Pool 保留分：

```text
0.86 × morphology
+0.14 × timing
```

最终 Winner：

```text
0.90 × morphology
+0.10 × timing
```

### Rescue 调整

```text
普通 Winner 门      0.50
第一 Rescue phase   1.50
第一 Rescue 门      0.20
波形 Rescue phase   1.65
```

## 6. v0.3.5 桌面 fiducial

- 首个模板必须来自高分 Winner；
- 普通搜索仍为 ±120 ms；
- 普通模板失配时，可在独立周期预测附近恢复；
- 也允许在固件 Winner 周围做 `<0.5×RR` 的宽恢复；
- 大偏移恢复同时要求高模板相关和独立节律一致；
- 连续失配时，仅允许高分 Winner 重新启动模板；
- `timing_recovered` 单独导出。
