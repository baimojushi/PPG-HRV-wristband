# v0.3.7 固定滞后整窗 PPG 纠错

## 目标

把“最多 8 秒输出延迟”转换为真正的未来证据，而不是冻结固件状态。

正式问题定义：

```text
给定过去约 12 秒 + 未来约 7.25 秒 PPG，
找出成熟区域内所有完整主波，并为每个主波选择一致的波顶。
```

Firmware Beat 只作为旁证，正式时间线可以独立于固件产生。

## 1. 全窗节律尺度

先对平滑并去慢基线后的 PPG 做自相关。

搜索 RR：

```text
300 ~ 1500 ms
```

自相关只得到节律尺度 `reference_rr_ms`。

它不会直接生成时间戳。

当当前自相关和过去正式 RR 接近时轻量融合；差异明显时允许全窗波形自己主导，避免旧节律拖住真实心率变化。

## 2. 主波候选

在统一极性后的真实 PPG 上寻找局部最大值。

动态突出度：

```text
max(绝对下限, robust amplitude × 比例)
```

最小候选距离按 reference RR 自适应。

每个候选的波形分数由：

```text
突出度
+
相对高度
```

构成。

## 3. 同周期次级峰竞争

两个局部峰如果间隔小于约半个 reference RR，只保留波形更强的一个。

这直接处理：

```text
主峰 + 次级同极性峰
切迹
宽峰内部多局部最大值
```

无需相信固件 predicted phase。

## 4. 长间隙补峰

如果两个已选主波之间的间隔超过约 1.55×RR：

```text
左主波
      ↓
推断跨越周期数
      ↓
在每个缺失槽位附近
使用更低突出度门寻找真实局部最大值
      ↓
补回漏检主波
```

槽位只缩小搜索区域。

最终补搏仍必须是实际 PPG 局部最大值。

## 5. 未来信息

实时正式提交点：

```text
latest_sample_t_us - 7.25 s
```

所以一个待提交波顶已经拥有后续多个完整主波。

未来证据用于：

```text
确定主周期
区分主峰和同周期次峰
发现长 gap
确认低幅主波
避免单个 Firmware Winner 决定下一周期
```

## 6. 波顶精修

离散最大值在 125 Hz 下约 8 ms 一点。

对最终局部最大值做三点抛物线插值：

```text
最多 ±0.5 Sample
```

只做局部亚采样细化，不允许跨峰移动。

## 7. Firmware Beat 的角色

每个正式波顶会尝试匹配附近的 Firmware Beat。

匹配信息用于：

```text
诊断固件偏移
统计固件漏检
统计固件多检
生成未来训练集
```

找不到 Firmware Beat 时，正式主波依然有效。

## 8. RR 清洗

正式 RR 清洗改为未来感知的对称局部节律。

旧单向历史存在风险：

```text
一次 RR 被拒绝
→ history 不更新
→ expected 不跟真实节律变化
→ 后续正常 RR 继续被拒绝
```

现在使用当前搏前后邻域建立稳健中位数。

持续、内部一致的真实心率变化可以由未来心搏确认；孤立短/长 RR 仍由结构规则处理。

## 9. 与视觉 Transformer 的接口

当前确定性解析器承担“视觉复核”的数学基线。

未来模型可以直接替换主波选择函数，输出：

```text
主波数量
波顶热力图
不确定区域
```

之后仍由原始 PPG 完成局部波顶精修。

这种分层可以直接比较：

```text
确定性整窗算法
vs
视觉 Transformer
```

而不需要改变 HRV 下游。
