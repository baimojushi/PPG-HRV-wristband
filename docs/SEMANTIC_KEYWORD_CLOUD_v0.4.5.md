# v0.4.5 动态状态关键词云

## 目标

在“节律心态匹配度 · 过去一小时”曲线下方增加一层更直观的状态语义。用户不需要理解频域、原型代码或冥想传统名称，只需要看到当前哪些日常状态含义在相似研究描述中反复出现。

## 语义来源

词云不对论文原文直接分词。论文中的同一身体状态可能使用不同英文术语、冥想传统名称或专业表述，直接按字面频次统计会把文化词和术语噪声放大。

因此，每个研究形态维护一组人工审查过的中文 `semantic_phrases`。这些短句只保留身体节律与日常体验层面的共同语义，例如：

- 平稳、均匀、有规律、少游移；
- 慢下来、舒缓、集中、持续投入；
- 起伏更丰富、起伏收窄、逐渐回稳；
- 过渡中、逐步调整、多种变化并存。

词云中不出现英文缩写、欧美冥想流派名称、宗教术语，也不把研究条件直接当成用户的心理身份。

## 权重规则

每个匹配研究形态首先得到案例相似程度 `case_similarity`。词云的核心权重为：

```text
形态语义权重
≈ 相似程度^1.35
× 轻量持续性修正
× 排名衰减
× 主结论轻量加权
× 该语义在该形态中的基础权重
```

关键原则：

1. 相似程度越高，该形态贡献给词云的语义越大；
2. 同一个语义被多个当前高相似形态共同支持时，贡献直接累加，所以“语义频率高”会自然得到更大字号；
3. `state_strength` 只做轻微稳定化，不取代当前相似程度；
4. 数据质量不会乘进语义相似权重，避免“信号稍差”被误解释成“身体形态变得不像”；
5. 暂时保留上一可靠结论时，主语义会轻微减弱，以表达“这是最近一次可靠认识”，但不会瞬间消失。

最终最多保留 12 个语义，并将累计分数压缩到 0.22–1.00 的显示权重，用于字号与透明度。

## UI

词云采用暖白到浅灰紫的低对比渐变背景，辅以极淡的绿色和紫色光晕；词语本身不使用胶囊标签，减少“功能面板感”。

状态刷新时，词语字号和透明度以约 34 毫秒一帧平滑逼近新权重。新的语义从较小字号进入，退出的语义逐渐淡出。布局使用响应式分行，在窄窗口下仍避免互相遮挡。

界面说明固定为：

> 把当前更相似的研究描述翻成日常中文；字越大，表示这个意思在当前相似研究里出现得越集中。它只描述节律形态，不代表对你的心情下结论。

## 可审计性

`research_state_table()` 现在会导出每个研究形态的 `semantic_phrases` 与基础权重；实时 `current_research_state` 会导出 `keyword_cloud`，其中包含：

- `text`：用户看到的中文语义；
- `weight`：显示权重；
- `semantic_score`：未归一化累计语义分；
- `support_count`：当前有多少个相似形态共同支持这个语义；
- `supporting_states`：支持它的研究形态名称。

因此 UI 的字号变化可以从导出数据中复核，而不是只存在于绘图层。
