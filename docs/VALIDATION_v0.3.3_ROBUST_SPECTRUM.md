结果显示：

- 最大上升斜率、半幅上升沿和二次插值峰值没有稳定提升 Welch/Lomb；
- 切线足点只有很小增益，同时改变 LF/HF；
- 当前数据不足以证明修改 Accepted Beat 时间戳有净收益。

所以 v0.3.3 不改固件心搏 fiducial，只优化频域互证尺度。
