# v0.4.4 · Research Case Library + Inclusive Matching

本版只重构研究案例与用户结论层，不改 v0.4.2 已稳定下来的 Beat / RR / corrected NN 核心，也不放宽 HRV 数据质量门。

## 为什么改

v0.4.3 解决了“一小时相似度曲线跳得太快”的问题，但仍把“用户有没有结论”绑定在少数特殊研究原型和较高生命周期门槛上。实测会话已经连续记录约 70 分钟，5 分钟频率结果有 184 / 208 个窗口真正成熟可用；旧版过去一小时仍只有 45 分钟 `STABLE_NEUTRAL` 与 14 分钟 `DATA_UNSTABLE`，用户长期看到的仍是“继续观察”。

这不是单纯阈值问题，而是产品层缺少两个结构：

1. 研究案例覆盖面太窄，普通稳定、整体增强、整体收窄、专注、安抚和任务后回弹等日常形态没有独立位置；
2. “相似程度”“数据可信程度”“状态持续程度”混成一个分数，导致有明显形态证据也未必能成为用户结论。

## 1. 研究库扩充

文献注册表由 8 条扩展到 16 条。新增来源覆盖：

- 自主慢呼吸的系统综述与荟萃分析；
- 自我关怀 / 安抚实验；
- 心理压力研究综述；
- 压力任务后的短时回弹；
- 持续注意与工作记忆任务；
- 压力后的专注冥想恢复；
- 情绪重新评价与任务后恢复；
- 正念 / 冥想随机对照研究的荟萃分析，用于明确“不能把更大的心跳起伏简单等同于冥想效果”的边界。

每篇来源新增：

```text
condition_detail   研究情境
evidence_level     证据类型
transfer_note      可迁移到产品的范围与限制
```

用户层仍采用：受试者 / 研究情境 / 一句观察结果 / [n] / 标题 / 作者。技术术语与神经系统标签不进入这些解释句。

## 2. 案例形态扩充

原有 6 个特殊案例继续保留，同时增加 7 个日常描述型案例：

```text
STEADY_EVEN               平稳而均匀
WHOLE_VARIABILITY_RISE    起伏整体变强
WHOLE_VARIABILITY_NARROW  起伏整体收窄
SOOTHING_DOWNSHIFT        安抚下来
FOCUSED_ENGAGEMENT        进入专注状态
REBOUND_RECOVERY          从紧绷中回弹
MIXED_TRANSITION          混合过渡中
```

因此，较慢和较快的心跳起伏一起上升或一起下降不再被视为“无法解释”；它们分别可以进入整体增强 / 整体收窄形态。

“平稳而均匀”和“混合过渡中”首先是身体节律本身的描述，允许没有一篇论文被硬套为直接依据。研究案例只有在条件足够接近时才附上。

## 3. 两阶段个人参照

v0.4.3 的正式参照通常需要二十多分钟才成熟。v0.4.4 改为：

```text
PROVISIONAL
  >= 3 个成熟可用窗口
  anchor 间隔约 4 分钟
  首尾跨度 >= 8 分钟
  排除最近 1 分钟

MATURE
  >= 4 个成熟可用窗口
  anchor 间隔约 5 分钟
  首尾跨度 >= 15 分钟
  排除最近 3 分钟
```

第一版参照用于 15 分钟产品里程碑；成熟参照继续负责更精细的长时间比较。两者都保持严格因果，不使用未来数据。

## 4. 正确拆开三个量

v0.4.4 为每个案例分别保存：

```text
case_similarity   身体数据本身与案例形态有多像
match_confidence  当前质量、时间覆盖、参照成熟度是否足够支持这次比较
state_strength    这种形态是否已经持续了一段时间
```

规则：

- LIMITED 只降低 `match_confidence`，不再把同一组生理数据的 `case_similarity` 乘小；
- 缺失特征不再当作 `z=0 / 正好位于个人常态`，而是从当前加权分母中移除；
- 如果剩余可用证据太少，该案例不评分；
- 一小时图继续使用较慢的 `state_strength`，保证轨迹不会因一两个更新点跳变；
- 主界面结论主要依据 `case_similarity + match_confidence`，不要求慢状态记忆先跨过旧的 0.70。

内部 lifecycle 门槛同步降低为：

```text
CANDIDATE >= 0.35
ACTIVE    >= 0.58 + 持续性 / 覆盖 / 稳定性条件
```

但用户有没有结论不再依赖 lifecycle。

## 5. 15 分钟 UX 里程碑

当会话达到 15 分钟、个人第一版参照已经形成且最近有效覆盖正常时：

- 若有研究案例达到温和展示条件，直接给 Top-K 最近案例；
- 若没有具体研究案例达到展示条件，从日常描述型案例里给出最接近的一种；
- 不再退回“暂无突出节律 / 继续观察”。

也就是说：**正常连续采集达到 15 分钟后，至少有一个稳定的身体节律结论。**

这条保证不适用于长时间数据缺失、没有成熟 5 分钟结果或传输 / 心搏时间线本身无法分析的情况。

## 6. 当前信号不好时保留最近可靠结论

短时 INVALID 不再把一个已经形成的长时间结论清零。

```text
当前不能刷新
    ↓
最多保留最近 12 分钟内的可靠结论
    ↓
UI：当前信号暂时不适合刷新判断。最近一次可靠结论仍是……
```

如果可靠结论已经太旧，则进入“当前不更新”，而不是伪造新结论。

使用本轮 `hrv_export.zip` 中的 `hrv_windows.csv` 回放：


## 8. 研究解释边界

本版研究来源只说明：某些实验或训练条件中曾出现过相似的身体节律组合。

禁止从实时 HRV 反向断言：

- 用户正在焦虑、放松、安全或抑郁；
- 用户正在进行某种冥想；
- 用户拥有某种长期心理特质；
- 某一种节律一定优于另一种节律。

研究库负责给身体形态提供可追溯参照，不承担医疗或心理诊断。
