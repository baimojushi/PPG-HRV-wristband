## 新增回归约束

1. 同一状态相似程度提高时，其语义累计分必须提高；
2. “平稳”等相同语义被多个当前相似研究形态共同支持时，支持计数与显示权重会累积；
3. 用户可见的关键词语义不得出现英文、Vipassana、Zen、正念、冥想、禅修等文化/专业标签；
4. 关键词云必须位于“节律心态匹配度”曲线下方、快慢节律趋势图上方；
5. 实时研究状态必须导出可审计的 `keyword_cloud` 数据，包含显示权重、累计语义分、支持次数与支持形态。
